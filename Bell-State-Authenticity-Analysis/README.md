# Bell State Authenticity Analysis

## Project Overview

Comparative analysis of different measures of
authenticity for Bell states.

We investigate three approaches:

1. Bell Inequality Violation (CHSH)
2. Quantum State Tomography (QST)
3. Interference Visibility

## Objectives

- Prepare the four Bell states.
- Evaluate their entanglement properties.
- Reconstruct density matrices using QST.
- Calculate interference visibility.
- Study the effect of different noise models.
- Compare all three measures.
